Setup Strategy Summary (for scratchpad)

    User installs WSL and a specified version of Ubuntu (e.g., 22.04).

    A single shell script (setup.sh) handles:

        Installing required tools: curl, lsb-release, apt-transport-https, etc.

        Installing and configuring Docker and Minikube

        Setting up environment variables or adding users to the docker group

    The script can detect Ubuntu version with lsb_release -cs and use it to correctly build MongoDB and other APT source list entries.

    Use requirements.txt to pin Python dependencies like:

flask==2.3.3
pymongo==4.6.1

In Dockerfiles, pin base image versions like:

FROM python:3.11-slim

Pin image versions in Kubernetes manifests or docker-compose.yml like:

    image: mongo:6.0.13

    Script should also install:

        kubectl

        helm (optional)

        Any dev utilities you rely on (e.g., jq, make, etc.)

End goal: user installs WSL + Ubuntu, then runs your setup.sh script to provision a full dev environment — no manual Python, MongoDB, or Docker setup needed.
